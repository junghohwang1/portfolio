대규모 공공 플랫폼 차세대 재구축 (SI)

2026 · 백엔드/풀스택

관리자·공급업체·수요기관 3개 포털과 도메인 API 로 나뉜 MSA 구조의 공공 거래 플랫폼 재구축 프로젝트에서 물품·카탈로그 도메인을 맡았습니다.

  • 화면·API 개발 — Thymeleaf·ES6 화면, BFF(OpenFeign 집계) → 도메인 API(MyBatis·PostgreSQL)까지 한 기능을 끝까지 구현
  • 레거시 이관 분석 — DB2 기반 기존 시스템의 SQL·배치를 역추적해 새 테이블 구조와의 차이·누락을 정리하고 범위 결정을 위한 근거 문서 작성
  • 배치 — Spring Batch(Tasklet·Chunk) 기반 집계·상태 변경 배치 설계와 이관
  • 품질 — 단위 테스트 시나리오를 실제 브라우저로 실행·판정하는 QC 자동화, 커밋 규칙(추적 ID) 검증 흐름 적용
  • 개발 생산성 — 화면 하나의 호출 흐름(화면 → BFF → API → SQL → 테이블)을 자동으로 그려 주는 분석 도구를 만들어 팀에 배포 (아래 「개발 지원 도구」)

Java 17 · Spring Boot 3 · Spring Batch · OpenFeign · MyBatis · PostgreSQL · Thymeleaf · ES6 · GitLab

Node.js · 사내 도구

여러 저장소로 나뉜 MSA 코드를 읽기 전용으로 정적 분석해, 화면 하나가 어떤 API·SQL·테이블을 거치는지 흐름도로 보여 주는 로컬 웹 도구입니다.

  • 화면 JS → 컨트롤러 → 서비스 → Feign → 다른 저장소 → MyBatis 매퍼 → 테이블 자동 추적
  • 배치(Job → Step → Tasklet → SQL)·외부 연계 흐름까지 같은 방식으로 표시
  • 테이블 명세·공통코드 조회, 읽기 전용 SQL 콘솔(자동완성·바인드 변수), 즐겨찾기 그룹
  • 설치·실행·흐름도 생성을 한 번에 하는 AI 코딩 도우미(Claude Code) 스킬로 묶어 팀원에게 배포
